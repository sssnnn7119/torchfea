# torchfea CAE UI

启动：

```bash
# fish + Conda
conda activate mine
python -m torchfea.ui
```

若当前终端尚未加载 Conda 的 fish 初始化，也可从任意 shell 直接运行：

```bash
conda run -n mine --no-capture-output python -m torchfea.ui
```

界面分为两个页面。前处理页面的模型树依次定义零件、OCC 几何特征、材料、节点集、单元集、表面集、装配实例、参考点、边界条件、载荷和静力隐式求解器；模型树上方的过滤框可按名称或类型快速定位对象。右侧有四个互相独立的视图：`Part Geometry`、`Part Mesh`、`Assembly Geometry`、`Assembly Mesh`。几何视图只显示 BREP 的点、OCC 曲线和实体面，所有未选中的面使用统一 CAD 面色并通过 OCC 边界线区分（面上的临时三角剖分不会作为网格线显示）；网格视图只显示有限元外表面的三角面片；Part 网格要在该 Part 的“剖分此 Part”完成后才能进入，Assembly 网格则要求所有 Part 都已剖分。装配体几何和网格视图会显示参考点标记。几何尺寸、OCC 特征或实例平移/转角在修改后会自动刷新 BREP（350 ms 防抖），同时使旧网格视图失效。拖拽鼠标直接旋转视图，滚轮缩放，中键拖拽平移；“充满视图”会将模型居中并缩放到当前窗口，`前/后/左/右/顶/底/等轴`按钮切换标准视角，“线框”和“边线”用于检查拓扑。视图中还显示带刻度的 XYZ 坐标轴。通过“新增零件”创建的零件会自动带一个 instance。点击右下角“提交计算 / 后处理”进入结果页面。

前处理页底部的“日志”按钮会显示详细日志路径。默认文件是当前工作目录下的 `torchfea_cae.log`，也可以在 fish 中指定：`set -x TORCHFEA_LOG_FILE /path/to/torchfea-cae.log`。日志会记录 OCC 特征、Gmsh 三维剖分、C3D4 数量、集合解析、控制器构建和求解 traceback。

“统一网格尺寸”是项目级唯一的体网格密度。点击“生成 FE 网格”或提交计算时，所有 Part 以同一尺寸调用 Gmsh 三维剖分；此后才会显示有限元网格。修改几何后，预览自动返回 BREP。工具栏的撤回/重做记录所有已应用的 CAD 特征和模型定义操作。数值框会立即更新 BREP；一个数值编辑结束时自动形成一个撤回步骤，不必为保留历史专门点击“应用”。每个 Part 的“几何 / 网格”节点下直接列出 CAD 特征；选中某一项可直接编辑该特征，应用后仍保持当前树位置和展开状态。

当前的真实几何入口完全基于独立的 Gmsh OCC 特征历史，不调用 `torchfea.model.cad`。点击 Part 下的“几何 / 网格”节点才显示“添加基本体 / 布尔运算 / 变换 / 剖分此 Part”；点击具体的 `Base-1` 等特征时，右侧只保留该特征的属性编辑，避免混淆操作上下文：

- 基本体：`Box`、`Wedge`、`Cylinder`、`Sphere`、`Cone`、`Torus`。
- 布尔特征：`Fuse`、`Cut`、`Intersect`、`Fragment`；两个或更多基本体可在同一 Part 的特征历史中组合。
- Part 内变换：`Translate`、`Rotate`、`Dilate`（非均匀缩放）、`Mirror`。它们直接改变 OCC 特征历史，和 assembly instance 的显示/装配变换是两层不同概念。
- 跨 Part 并集：工具栏“Part 并集合并”固定调用 OCC `fuse`，把两个未施加 instance 平移/转角的 Part 合并为一个带并集特征历史的新 Part；差集、交集和分割在 Part 的 CAD 特征历史中完成。

跨 Part 合并会更改 Gmsh 实体编号，所以若源 Part 已存在节点集、单元集、表面集、边界或载荷，界面会拒绝操作，避免悄悄破坏选择定义。合并后重新在 BREP 中拾取这些集合即可。

自定义节点集和单元集使用零基编号，例如 `0, 3:8, 12`；区间包含两端。自定义表面集使用 `单元号:面号`，如 `0:1, 2:3`，面号从 1 起计。每个 Part 都有一个自动汇总全部外部面的外表面，默认名为 `extern`；它位于 Part 上，只能重命名，不能删除。剖分后系统生成 `all`（全部节点）、`all`（全部单元）和 `surface_all`（全部外表面节点）。每个自定义 surface 另外生成唯一的 `surface_<表面名>_nodes` 节点集；外表面不再额外生成重复的节点集。系统集合只读，不能被自定义集合覆盖。Instance 只定义所属 Part、平移和转角，显示时自动使用所属 Part 的外表面。

创建一个集合后，选中该集合并使用“从预览选节点 / 体 / 面”：界面会自动切换到当前 Part 的 BREP 预览并进入对应选择模式。CAD 顶点以白色小球明确标识，仅在“选节点”模式下可拾取；选中后变为橙黄色。节点集合点击该顶点后会在最终剖分时解析为对应 Gmsh 顶点节点；单元集合点击 BREP 体后会解析为该体的全部单元；表面集合点击独立的 BREP 面后会解析为对应单元面。当前选中的 BREP 曲面显示为红色，并在集合写入后保持高亮；模型树中的 Part 外表面会将该 Part 的全部 BREP 子面同时标红。选择结束后视图自动回到拖拽导航模式。

材料位于 Part 子节点下。选中“材料”根节点可单独设置该 Part 材料集合的密度；密度会写入所有元素块并用于质量矩阵。支持线弹性、Neo-Hookean 和 Neo-Hookean lnJ；每个材料通过一个单元集分配，多个材料不能重叠且必须覆盖该 Part 的全部单元。载荷类型包括压力（目标为表面集）、体力（目标为零件内单元块名）和集中力（目标为参考点）。位移边界条件使用实例上的节点集和 U1/U2/U3 约束。单元集已经可用于材料分配、选择和 `.inp` 导出。

文件菜单提供三种互补导出：

- `*.torchfea.json`：可再次打开的界面定义。
- `*.npz`：调用 `FEAController.save_model` 写出的完整原生 torchfea 模型。
- `*.inp`：调用 `Part.export_inp` 写出的 Abaqus Part deck，包含节点、单元、Nset、Elset 与 Surface。多零件会各写一个文件。

## 诊断策略

UI 到 Gmsh/torchfea 的边界不再用旧结果或默认对象掩盖失败：缺少 OCC 特征、重复/失效历史引用、空 BREP 面、缺少四面体、集合越界、实例/载荷/边界引用不存在时会立即报错并清空对应视图。Part 外表面始终自动重建为全部边界面，重命名不会改变其覆盖范围。旧工程只有在没有 `operations` 时才迁移成单个 OCC 特征，并写入日志。

目前保留的兜底只有两类：Gmsh 曲线闭环失败时通过 STEP 导入重建拓扑（重建前后会比较 OCC 体积，改变布尔结果就直接失败），以及 PyVista 不可用时使用 VTK 原生渲染。它们都会写日志；网格或 BREP 失败不会继续显示上一次缓存。
